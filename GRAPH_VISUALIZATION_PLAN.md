# План визуализации графа на WPF

## Оценка сложности: **СРЕДНЯЯ** (2-3 часа работы)

## Преимущества для вашего случая:

✅ У вас уже есть **иерархическая структура** (уровни) - это упрощает компоновку  
✅ Граф **ациклический** (только сверху вниз) - проще рисовать  
✅ Не нужен интерактивный редактор - только просмотр  

## Что потребуется:

### 1. **Базовые элементы WPF:**
- `Canvas` - для позиционирования узлов и стрелок
- `Ellipse` или `Border` - для узлов (целей)
- `Line` или `Path` - для стрелок (связей)
- `TextBlock` - для подписей

### 2. **Алгоритм компоновки:**
- Размещение узлов по уровням (горизонтальные ряды)
- Выравнивание узлов внутри уровня
- Расчет позиций для стрелок

### 3. **Интерактивность (опционально):**
- `ScrollViewer` - для прокрутки больших графов
- Zoom (масштабирование) - через `RenderTransform`
- Панорамирование - через `Transform`

## План реализации:

### Вариант 1: Простой (рекомендую)
**Время: 2-3 часа**

```
1. Новая вкладка "Граф" в MainWindow
2. UserControl GraphView с Canvas
3. Алгоритм компоновки:
   - Узлы по уровням (сверху вниз)
   - Равномерное распределение по ширине
   - Стрелки как линии с наконечниками
4. ScrollViewer для прокрутки
```

**Сложность:** ⭐⭐☆☆☆ (средняя)

### Вариант 2: С зумом и панорамированием
**Время: 4-5 часов**

```
+ Добавить масштабирование (колесо мыши)
+ Добавить панорамирование (зажатая мышь)
+ Индикатор масштаба
```

**Сложность:** ⭐⭐⭐☆☆ (выше средней)

### Вариант 3: Интерактивный редактор
**Время: 8-10+ часов**

```
+ Перетаскивание узлов
+ Редактирование связей через UI
+ Сохранение позиций узлов
```

**Сложность:** ⭐⭐⭐⭐⭐ (высокая)

## Рекомендация:

Начните с **Варианта 1** - простой, но функциональный граф:
- Быстрая реализация
- Понятная визуализация
- Хорошо работает для иерархических структур
- Можно потом добавить зум, если понадобится
