# Предпроектные исследования: модуль графа целей

WPF-приложение для построения многоуровневого графа целей и расчета их абсолютных весов на этапе предпроектных исследований.

## Назначение

Приложение предназначено для анализа системных целей проекта через построение иерархического графа целей различных уровней (от общественных до личных) и расчета их абсолютных весов на основе матричного анализа связей.

## Основные возможности

### 1. Управление проектом

- **Новый проект** — создание пустого проекта
- **Открыть проект** — загрузка проекта из JSON-файла
- **Сохранить проект** — сохранение проекта в JSON-файл

Все операции доступны через кнопки на верхней панели инструментов.

### 2. Уровни и цели

Вкладка "Уровни и цели" содержит единую таблицу с иерархической структурой:

- **Уровни** отображаются как заголовки (жирным шрифтом)
- **Цели** перечисляются непосредственно под соответствующим уровнем
- Между последней целью уровня и следующим уровнем автоматически добавляется пустая строка

**Операции:**
- Добавление уровня: введите название и нажмите "Добавить уровень"
- Добавление цели: выберите уровень, введите название и относительный вес (r ∈ [0..1]), нажмите "Добавить цель"
- Удаление уровня/цели: выделите строку и нажмите соответствующую кнопку удаления
- Редактирование веса: двойной клик по ячейке "Вес (r)" и ввод нового значения

**Особенности:**
- Коды целей генерируются автоматически в формате L-C (номер уровня — номер цели на уровне)
- Сумма весов всех целей на каждом уровне должна быть равна 1.0
- При удалении уровня автоматически удаляются все цели этого уровня и связанные связи

**Шаблоны:** Кнопка "Добавить из шаблона" позволяет быстро добавить стандартные уровни (Человечество, Государство, Отрасль и т.д.).

### 3. Связи между целями

Вкладка "Связи" позволяет задавать зависимости между целями:

- **Добавление связи:** выберите цель-предшественник и цель-последователь, нажмите "Добавить связь"
- **Удаление связи:** выделите связь в таблице и нажмите "Удалить связь"

**Ограничения:**
- Связи разрешены только из уровня i в более нижний уровень k > i (сверху вниз)
- Запрещены циклы, петли, связь на тот же уровень или вверх по иерархии

### 4. Расчеты

Вкладка "Расчет" содержит несколько подразделов:

#### Матрицы

- **Матрица A (смежности):** отображает наличие связей между целями (0 или 1)
- **Матрица W (весов):** рассчитывается как W[p,q] = A[p,q] × (r_p × r_q)

Матрицы отображаются в виде таблиц, где строки и столбцы соответствуют кодам целей в отсортированном порядке.

#### Результаты расчета

Таблица результатов содержит следующие колонки:
- **Связи:** входящие (←) и исходящие (→) связи цели
- **Цели:** код и название цели
- **Абсолютный вес:** рассчитанное значение R
- **Ранг:** место цели в рейтинге по убыванию абсолютного веса

**Сортировка:** доступна по любой колонке с выбором направления (по возрастанию/убыванию).

**Фильтрация:**
- Отметьте "Отфильтровать по минимальному весу" и укажите пороговое значение
- В таблице "Все результаты" будут показаны только цели с абсолютным весом выше указанного порога

**Топ-10:**
- "10 лучших" — цели с наибольшими абсолютными весами
- "10 худших" — цели с наименьшими абсолютными весами

**Обрезка графа:** функция "Обрезать граф" удаляет все цели с абсолютным весом ниже указанного порога вместе со всеми связанными связями. После обрезки автоматически выполняется пересчет.

### 5. Визуализация графа

Вкладка "Граф" отображает графическое представление структуры целей:

- Узлы расположены по уровням (сверху вниз)
- Стрелки показывают связи между целями
- Каждый узел отображает код цели, название, относительный вес (r) и абсолютный вес (R)
- Граф автоматически обновляется после изменений проекта или выполнения расчетов

**Примечание:** Граф предназначен только для просмотра, редактирование через него невозможно.

## Алгоритм расчета

1. Цели сортируются по уровню и номеру на уровне
2. Создается матрица смежности A размером N×N, где A[p,q] = 1 если есть связь Goal[p] → Goal[q], иначе 0
3. Создается матрица весов W размером N×N, где W[p,q] = A[p,q] × (r_p × r_q)
4. Для каждой цели q рассчитывается абсолютный вес: R_q = r_q + Σ(по всем p) W[p,q]
5. Результаты сортируются по убыванию R с присвоением рангов

## Валидация

Перед расчетом выполняется проверка:

- Проект не должен быть пустым
- Каждый уровень должен содержать хотя бы одну цель
- Сумма весов целей на каждом уровне должна быть равна 1.0
- Веса целей должны находиться в диапазоне [0..1]
- Все связи должны быть корректными (направлены сверху вниз, без циклов и петель)

При обнаружении ошибок расчет блокируется, а список ошибок отображается в окне предупреждения.

## Формат данных

Проекты сохраняются в формате JSON со следующей структурой:

```json
{
  "Title": "Название проекта",
  "Levels": [
    { "Index": 1, "Name": "Название уровня" }
  ],
  "Goals": [
    {
      "Code": "1-1",
      "LevelIndex": 1,
      "Name": "Название цели",
      "RelativeWeight": 0.5
    }
  ],
  "Links": [
    {
      "FromGoalCode": "1-1",
      "ToGoalCode": "2-1"
    }
  ]
}
```

## Системные требования

- .NET 8.0 или выше
- Windows 10/11
- Поддержка разрешений до 2560×1440 пикселей

## Запуск приложения

1. Убедитесь, что установлен .NET 8.0 SDK
2. Откройте проект в Visual Studio или запустите через командную строку:
   ```bash
   dotnet build
   dotnet run
   ```

## Рекомендации по использованию

1. Начните с создания уровней иерархии, начиная с верхнего уровня
2. Добавьте цели на каждый уровень, убедившись, что сумма весов на уровне равна 1.0
3. Установите связи между целями различных уровней
4. Выполните расчет и проанализируйте результаты
5. Используйте фильтрацию и топ-10 для выявления наиболее и наименее значимых целей
6. При необходимости используйте обрезку графа для упрощения структуры
7. Сохраните проект для дальнейшего использования

## Технические детали

- **Архитектура:** MVVM (Model-View-ViewModel) без использования сторонних фреймворков
- **Платформа:** .NET 8 + WPF
- **Сериализация:** JSON (Newtonsoft.Json)
- **UI:** Табличное представление данных, минималистичный интерфейс

Приложение создано как учебный проект для демонстрации применения методов матричного анализа в задачах предпроектных исследований системных целей.
