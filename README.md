# Предпроектные исследования: модуль графа целей

WPF-приложение для построения многоуровневого графа целей и расчета их абсолютных весов.

## Технические требования

- .NET 8.0
- WPF (Windows Presentation Foundation)
- Паттерн MVVM (без сторонних фреймворков)

## Функциональность

### 1. Управление проектом
- Создание нового проекта
- Открытие проекта из JSON файла
- Сохранение проекта в JSON файл

### 2. Уровни
- Добавление уровней с названиями
- Удаление уровней (с автоматическим удалением целей этого уровня и связанных связей)
- Индексация уровней начинается с 1

### 3. Цели
- Добавление целей на выбранный уровень
- Автоматическая генерация кода цели в формате L-C (уровень-номер)
- Установка относительного веса (r ∈ [0..1])
- Обновление веса существующей цели
- Удаление цели (с автоматическим удалением связанных связей)
- Проверка суммы весов по уровням (должна быть = 1.0)

### 4. Связи
- Добавление связей между целями (только сверху вниз: из уровня i в уровень k > i)
- Удаление связей
- Валидация связей (запрет циклов, петель, связей на тот же уровень или вверх)

### 5. Расчеты
- Расчет матрицы смежности A (N × N)
- Расчет матрицы весов W (N × N)
- Расчет абсолютных весов R для каждой цели
- Сортировка результатов по убыванию абсолютного веса с присвоением рангов

### 6. Валидация
Проверка на:
- Пустой проект
- Пустой список целей
- Уровни без целей
- Сумма весов уровня != 1.0
- Недопустимые связи (один уровень, вверх, петля)
- Цели без введенного веса

## Формат JSON проекта

```json
{
  "Title": "Project Name",
  "Levels": [
    { "Index": 1, "Name": "Level Name" }
  ],
  "Goals": [
    { "Code": "1-1", "LevelIndex": 1, "Name": "Goal Name", "RelativeWeight": 0.5 }
  ],
  "Links": [
    { "FromGoalCode": "1-1", "ToGoalCode": "2-1" }
  ]
}
```

## Алгоритм расчета

1. Цели сортируются по уровню и номеру на уровне
2. Создается матрица смежности A, где A[p,q] = 1 если есть связь Goal[p] → Goal[q]
3. Создается матрица весов W, где W[p,q] = A[p,q] × (r_p × r_q)
4. Абсолютный вес цели q: R_q = r_q + Σ(по всем p) W[p,q]
5. Результаты сортируются по убыванию R с присвоением рангов

